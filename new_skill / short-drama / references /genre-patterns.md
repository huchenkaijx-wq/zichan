# 短剧类型套路模板

## 都市逆袭类

### 核心公式
平凡主角 → 获得机遇/身份曝光 → 打脸反派 → 持续升级

### 爽点设计
- 第1集：主角被羞辱，埋下身份伏笔
- 第3集：小反转，反派惊讶
- 第5集：身份初露，众人震惊
- 第10集：大反转，彻底打脸

### 经典桥段
- 身份曝光："他其实是..."
- 实力碾压："就凭你？"
- 众人跪舔："我们有眼不识泰山"

### 细分类型
1. **赘婿逆袭**：上门女婿隐藏身份，被羞辱后曝光
2. **职场逆袭**：小职员获得机遇，一步步爬上高位
3. **神豪系统**：获得系统，花钱就能变强
4. **战神归来**：退役兵王回归都市，保护家人

---

## 甜宠恋爱类

### 核心公式
相遇 → 误会 → 心动 → 暧昧 → 确认关系 → 撒糖

### 爽点设计
- 每2集一个甜蜜互动
- 每5集一个感情升级
- 每10集一个重大进展

### 经典桥段
- 壁咚/床咚
- 吃醋名场面
- 英雄救美
- 误会解除后的深情告白
- 霸道总裁宠妻

### 细分类型
1. **霸道总裁**：冷酷总裁爱上平凡女孩
2. **先婚后爱**：被迫结婚，先婚后爱
3. **青梅竹马**：从小一起长大，终成眷属
4. **契约恋爱**：假戏真做，从契约到真心

---

## 古装穿越类

### 核心公式
穿越 → 适应 → 利用现代知识 → 逆袭 → 收获爱情/权力

### 爽点设计
- 用现代知识碾压古人
- 现代观念冲击古代人
- 身份从低到高的晋升

### 经典桥段
- "我可是来自21世纪的人"
- 现代商业思维在古代赚钱
- 用现代医术救人
- 诗词歌赋震惊全场

### 细分类型
1. **穿越成妃**：现代女穿越成古代妃子，宫斗逆袭
2. **穿越成商**：用现代商业知识在古代经商
3. **穿越成医**：用现代医学在古代行医
4. **穿越成将**：用现代军事知识带兵打仗

---

## 悬疑推理类

### 核心公式
案件发生 → 调查 → 线索 → 反转 → 真相

### 爽点设计
- 每集一个新线索
- 每3集一个误导
- 每10集一个案件完结

### 经典桥段
- "凶手就在我们之中"
- 关键证据出现
- 凶手自白
- 时间线推理

### 细分类型
1. **刑侦破案**：警察破案，抽丝剥茧
2. **密室推理**：封闭空间内的推理
3. **心理悬疑**：心理战，谁是真凶
4. **复仇悬疑**：为亲人复仇，追查真相

---

## 重生复仇类

### 核心公式
前世惨死 → 重生归来 → 复仇计划 → 打脸仇人 → 圆满人生

### 爽点设计
- 第1集：前世回忆，建立仇恨
- 第3集：开始布局，仇人入套
- 第5集：小复仇成功，仇人痛苦
- 第10集：大仇得报，仇人绝望

### 经典桥段
- "这一世，我不会再让你们得逞"
- 提前知道未来，布局反杀
- 仇人自食恶果
- 前世错过的真爱，这一世珍惜

### 细分类型
1. **重生复仇**：重生后向仇人复仇
2. **重生逆袭**：重生后改变命运，走上巅峰
3. **重生追爱**：重生后追回前世错过的爱情
4. **重生养娃**：重生后保护孩子，改变命运

---

## 神豪系统类

### 核心公式
获得系统 → 完成任务 → 获得奖励 → 花钱打脸 → 不断升级

### 爽点设计
- 每集完成一个任务，获得奖励
- 用钱解决问题，打脸看不起自己的人
- 系统升级，能力越来越强

### 经典桥段
- "叮！任务完成，奖励已发放"
- "这张卡里有十个亿，拿去花"
- "你不是很嚣张吗？现在跪下"
- 拍卖会一掷千金

### 细分类型
1. **花钱系统**：花钱就能变强，越花越强
2. **签到系统**：每天签到获得奖励
3. **选择系统**：做出选择获得奖励
4. **直播系统**：直播获得打赏，兑换能力

---

## 战神归来类

### 核心公式
战神退役 → 回归都市 → 家人被欺 → 身份曝光 → 保护家人

### 爽点设计
- 第1集：家人被欺负，战神隐忍
- 第3集：小喽啰来犯，战神出手
- 第5集：身份初露，敌人惊恐
- 第10集：身份完全曝光，敌人跪地求饶

### 经典桥段
- "龙帅到！"
- "参见战神！"
- "动我家人者，死！"
- 十万将士齐声参见

### 细分类型
1. **龙帅归来**：龙帅退役，保护妻女
2. **兵王归来**：兵王回归，复仇雪恨
3. **至尊归来**：至尊强者回归都市
4. **神医归来**：神医下山，救死扶伤

---

## 虐恋情感类

### 核心公式
相爱 → 误会 → 分离 → 痛苦 → 真相大白 → 破镜重圆

### 爽点设计
- 前期虐心，让观众心疼主角
- 中期误会加深，情绪压抑
- 后期真相大白，情绪释放
- 结局破镜重圆，撒糖补偿

### 经典桥段
- "你听我解释..." "我不听！"
- "原来一切都是误会"
- "对不起，我来晚了"
- "这些年，你过得好吗？"

### 细分类型
1. **误会虐恋**：因为误会而分离
2. **家族虐恋**：家族恩怨导致不能在一起
3. **替身虐恋**：替身文学，真假难辨
4. **失忆虐恋**：一方失忆，另一方守护

---

## 搞笑喜剧类

### 核心公式
设定奇葩情境 → 制造误会 → 搞笑冲突 → 意外结局

### 爽点设计
- 每集多个笑点
- 反转出人意料
- 角色反差萌

### 经典桥段
- 误会引发的搞笑场面
- 角色互换身份
- 阴差阳错的巧合
- 反转不断的剧情

### 细分类型
1. **职场喜剧**：办公室搞笑日常
2. **家庭喜剧**：家庭生活中的趣事
3. **穿越喜剧**：穿越后的搞笑经历
4. **误会喜剧**：一系列误会引发的搞笑故事

| 重生复仇 | 女频为主 | 复仇、改变命运 | 中 |
| 神豪系统 | 男频为主 | 花钱、升级 | 低 |
| 战神归来 | 男频为主 | 霸气、保护 | 低 |
| 虐恋情感 | 女频为主 | 虐心、感动 | 中 |
