# 短剧剧本格式规范

## 标准剧本格式

### 场景标题格式
```
第X集
场景：地点 - 时间（日/夜/晨/昏）
```

### 人物标注
- 角色名后加冒号，台词另起一行
- 动作描述用括号括起来
- 示例：
```
林晓：（愤怒地）你凭什么这样对我！
```

### 镜头提示
- [特写] - 人物表情特写
- [全景] - 场景全貌
- [闪回] - 回忆画面
- [黑屏] - 转场效果

## 分集结构模板

```
第X集：【集标题】

场景：地点 - 时间

[镜头提示]

角色A：（情绪）台词内容

角色B：（动作）台词内容

[转场]

场景：地点 - 时间

...

【本集完】
```

## 时长控制
- 1分钟 ≈ 250-300字
- 2分钟 ≈ 500-600字
- 3分钟 ≈ 800-1000字

## 钩子设计位置
- 集首：承接上集悬念
- 集中：冲突升级
- 集尾：必须留悬念
