# 短剧剧本创作

## 任务目标
- 本 Skill 用于创作各类短剧剧本（1-3分钟/集，共10-100集）
- 能力：剧情大纲设计、分集脚本撰写、角色设定、台词创作、爽点设计
- 触发：用户提到"短剧"、"剧本"、"写个剧情"、"分集脚本"、"角色设定"等关键词

## 前置准备
- 无需额外依赖，纯智能体能力完成

## 操作步骤

### 1. 需求确认
在与用户对话中确认以下关键信息：
- **短剧类型**：都市情感、古装穿越、悬疑推理、职场逆袭、甜宠恋爱、重生复仇、神豪系统、战神归来等
- **集数规划**：通常10-100集，每集1-3分钟
- **风格定位**：爽文、甜宠、虐恋、搞笑、悬疑、恐怖等
- **核心卖点**：反转、打脸、甜宠、逆袭、悬疑、搞笑等
- **目标受众**：男频/女频、年龄段、偏好题材
- **特殊要求**：是否有特定场景、人物原型或禁忌内容

### 2. 角色设定
**必须先读取** [references/character-archetypes.md](references/character-archetypes.md) 获取角色设计参考

#### 主角设计要素
- **基础信息**：姓名、年龄、外貌特征、职业身份
- **隐藏身份**（如有）：真实身份、隐藏能力、背景故事
- **性格特点**：3-5个核心性格标签
- **核心动机**：为什么做这件事？目标是什么？
- **成长弧线**：从什么状态到什么状态？
- **经典台词**：2-3句能体现角色性格的金句

#### 反派设计要素
- **与主角关系**：为什么针对主角？
- **作恶动机**：嫉妒？利益？仇恨？
- **手段风格**：明着来还是暗中使绊？
- **结局预设**：如何被击败？什么下场？

#### 配角设计要素
- **助攻型**：如何帮助主角？关键时刻的作用？
- **情感型**：与主角的感情线如何发展？
- **搞笑型**：制造什么类型的笑点？

#### 输出格式
```
【主角】XXX
- 身份：表面... / 实际...
- 性格：...
- 动机：...
- 台词风格：...

【反派】XXX
- 身份：...
- 与主角冲突：...
- 结局：...

【配角】XXX
- 作用：...
- 特点：...
```

### 3. 剧情大纲
**必须先读取** [references/genre-patterns.md](references/genre-patterns.md) 获取该类型的创作套路

#### 大纲结构
1. **故事背景**：时间、地点、世界观设定
2. **主线剧情**：起承转合的完整脉络
3. **分卷/分阶段规划**：
   - 第1-10集：铺垫期，建立人物关系，埋下伏笔
   - 第11-30集：发展期，冲突升级，小高潮不断
   - 第31-60集：高潮期，核心矛盾爆发，身份曝光
   - 第61-100集：收尾期，解决所有矛盾，圆满结局
4. **爽点分布表**：明确每5-10集的大爽点
5. **钩子设计**：每10集一个 cliffhanger

#### 输出格式
```
## 剧情大纲

### 故事背景
...

### 主线脉络
起：...
承：...
转：...
合：...

### 分阶段规划
第一阶段（1-10集）：...
第二阶段（11-30集）：...
...

### 爽点分布
- 第X集：...
- 第X集：...
```

### 4. 分集脚本
**必须先读取** [references/drama-formats.md](references/drama-formats.md) 了解标准格式

#### 单集结构
1. **集标题**：概括本集核心冲突（10字以内）
2. **场景列表**：本集涉及的所有场景
3. **剧情简介**：100字以内概括本集内容
4. **正文剧本**：
   - 场景标题（地点+时间）
   - 镜头提示
   - 人物对话（情绪+台词）
   - 动作描述
   - 转场提示
5. **本集钩子**：结尾悬念，引导看下一集

#### 时长控制
- 1分钟短剧：250-300字，1-2个场景
- 2分钟短剧：500-600字，2-3个场景
- 3分钟短剧：800-1000字，3-4个场景

#### 输出格式
```
### 第X集：【集标题】

**场景**：地点1、地点2...

**剧情简介**：...

**场景：地点 - 时间**

[镜头提示]

角色A：（情绪）台词

角色B：（动作）台词

[转场]

**场景：地点 - 时间**

...

**【本集钩子】**：...
```

### 5. 台词优化
**必须先读取** [references/dialogue-guide.md](references/dialogue-guide.md) 获取台词创作技巧

#### 优化要点
- **口语化**：避免书面语，使用日常表达
- **个性化**：不同角色有不同的说话风格
- **情绪化**：台词要承载情绪，有张力
- **信息密度**：每句台词都要有作用，不能废话
- **金句设计**：每集1-2句能让人记住的台词

#### 台词类型
- **冲突型**："你凭什么..."、"就凭你？"
- **反转型**："其实我是..."、"你们不知道的是..."
- **情感型**："我等你三年了"、"对不起，我来晚了"
- **霸气型**："我说的话，就是规矩"、"跪下！"

### 6. 爽点设计
**必须先读取** [references/hook-formulas.md](references/hook-formulas.md) 获取爽点设计公式

#### 爽点类型
- **身份反转**：隐藏身份曝光
- **实力碾压**：用实力打脸反派
- **情感爆发**：压抑后的情绪释放
- **智慧碾压**：用计谋战胜对手
- **财富碾压**：用钱解决问题
- **颜值暴击**：外貌惊艳全场

#### 爽点节奏
- **小爽点**：每1-2集一个（小反转、小打脸）
- **中爽点**：每5-10集一个（身份初露、重要胜利）
- **大爽点**：每20-30集一个（彻底打脸、重大转折）

## 注意事项
- **附件读取规则**：当任务涉及特定类型短剧、台词创作或爽点设计时，**必须优先读取** references/ 中的相关文档，不要凭推测执行
- **爽点密度**：短剧节奏快，每集必须有冲突或反转，不能平淡
- **台词风格**：避免书面语，使用口语化、有冲击力的表达
- **钩子设计**：每集结尾必须留悬念，引导观众看下一集
- **角色鲜明**：主角必须有明确的目标和动机，反派必须足够可恨
- **情绪递进**：从压抑到爆发要有层次，不能一蹴而就
- **信息密度**：每句台词、每个场景都要有作用，避免水剧情
